# Prompt Comparison

This section compares basic prompts with improved prompts for different AI tasks.

## Example 1 — Summarization

### Basic Prompt

Summarize this text.

### Improved Prompt

Summarize the given text in 3 bullet points using simple English. Include only the most important information.

### Improvement

The improved prompt specifies the length, format, language, and expected level of detail.

---

## Example 2 — Information Extraction

### Basic Prompt

Extract information from this text.

### Improved Prompt

Extract the product name, brand, ingredients, price, and target users from the text. If information is missing, write "Not mentioned."

### Improvement

The improved prompt clearly defines the information that needs to be extracted.

---

## Example 3 — Classification

### Basic Prompt

Classify this product.

### Improved Prompt

Classify the product into one of these categories: Skincare, Makeup, Haircare, Fragrance, or Other. Return only the category name.

### Improvement

The improved prompt provides categories and specifies the output format.

---

## Example 4 — Question Answering

### Basic Prompt

Answer this question.

### Improved Prompt

Answer the question using only the information provided in the text. Give the answer in one sentence and do not add unsupported information.

### Improvement

The improved prompt limits the source of information and controls the output.

---

## Example 5 — Translation

### Basic Prompt

Translate this into English.

### Improved Prompt

Translate the text into simple English while keeping the original meaning. Do not add or remove information.

### Improvement

The improved prompt clearly defines the required translation style.

---

## Example 6 — Sentiment Classification

### Basic Prompt

Analyze this review.

### Improved Prompt

Classify the review as Positive, Negative, or Neutral. Give one short reason for your classification.

### Improvement

The improved prompt provides the possible categories and asks for a reason.

---

## Example 7 — Email Writing

### Basic Prompt

Write an email.

### Improved Prompt

Write a polite professional email asking an HR manager for an update about a job application. Keep it under 100 words and use simple English.

### Improvement

The improved prompt provides the purpose, audience, tone, length, and language.

---

## Example 8 — Product Review

### Basic Prompt

Write a review for this product.

### Improved Prompt

Write a 50-word product review using only the information provided. Mention the product type, key features, and suitable users. Do not invent benefits.

### Improvement

The improved prompt controls the length and prevents unsupported information.

---

## Example 9 — Structured Extraction

### Basic Prompt

Find the important information.

### Improved Prompt

Extract the product name, price, rating, and brand. Present the result in a table. If information is unavailable, write "Not mentioned."

### Improvement

The improved prompt defines exactly what information and format are required.

---

## Example 10 — Short Answer

### Basic Prompt

Explain this.

### Improved Prompt

Explain the concept in simple English using exactly 3 bullet points. Each bullet point should contain one important idea.

### Improvement

The improved prompt specifies the language, number of points, and structure.
